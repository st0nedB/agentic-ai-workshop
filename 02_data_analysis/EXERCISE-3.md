# Exercise 3 — Draw the actual workflow

**Block 2 · 35 minutes · Group work**

## Prerequisites

Use the analysis code and outputs from [Exercise 2](README.md). The exercise requires the workshop Excalidraw MCP integration; the organizer will provide connection details. Verify that drawing tools are available in your chosen agent before starting.

If Exercise 2 is incomplete, use the [synthetic reference analysis](fallback/README.md) instead. Do not present it as your own analysis of real measurements.

## Assignment

Ask the agent to inspect the actual analysis code and create an editable Excalidraw diagram of its workflow. Show the input, file loading, data transformations, visualization and outputs. Do not invent processing steps.

1. **Connect and inspect (10 min):** Connect Excalidraw MCP and identify the code, input and outputs to be visualized.
2. **Draw (15 min):** Ask the agent to create a diagram using the MCP drawing tools. Observe the actual tool calls.
3. **Verify (10 min):** Compare each node and edge with the implementation. Correct missing or invented steps, incorrect labels and unexplained branches.

Save the editable diagram as `02_data_analysis/results/workflow.excalidraw` (export it from Excalidraw if necessary). Record the source script used and any limitations in `results/WORKFLOW.md`.

**Success:** The diagram is editable, includes named inputs and outputs, accurately represents the executed code, and can be opened in Excalidraw.
